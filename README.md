# InternetUseAliens

Інтерактивний курс безпечного користування інтернетом для тих, хто вперше побачив мережу: короткі уроки → тест після кожного → прогрес. Завдання та дорожня карта — у [TASKS.md](TASKS.md).

## Структура

```
content/                 # увесь навчальний матеріал (редагується без коду)
  course.json            # назва, поріг складання, порядок модулів, параметри іспиту
  trainer.json           # приклади для тренажера «Шахрай чи ні»
  modules/NN-назва/
    lesson.md            # урок (markdown: #, ##, - списки, **жирний**)
    quiz.json            # питання: single | multi | truefalse
src/internetusealiens/   # CLI: валідація контенту, збірка, локальний сервер
site/                    # статичний плеєр (HTML/CSS/JS, без залежностей)
tests/                   # unittest
docs/                    # методичні принципи, гайд для авторів
```

## Команди

```
uv run internetusealiens validate   # перевірка уроків і тестів
uv run internetusealiens build      # content/ -> site/course.json
uv run internetusealiens serve      # збірка + http://localhost:8000
uv run python -m unittest discover tests
```

## Формат питання

```json
{ "id": "m01-q1", "type": "single|multi|truefalse", "text": "...",
  "options": ["..."], "answer": [1], "explanation": "Чому саме так" }
```
Для `truefalse` — без `options`, `answer: true/false`. `explanation` обовʼязкове: тест має вчити, а не лише оцінювати.

## Принципи
- Один урок — одна ідея, 3–5 хвилин читання, великий шрифт, проста мова.
- Правило + приклад із життя + практичне завдання.
- Прогрес зберігається лише локально в браузері; персональних даних не збираємо.

## Учасники й прогрес
Під час першого відкриття сайт питає імʼя або псевдонім. Профілів може бути кілька (кожен зі своїм прогресом); перемикання — кнопка з іконкою людини вгорі. Усе зберігається в `localStorage` цього браузера, пароль не потрібен.

Справжні логін і пароль потребують сервера (база користувачів, хешування паролів, HTTPS, відновлення доступу). Це суперечило б принципу курсу «мінімум даних», тому на старті їх немає. Якщо знадобиться спільна статистика групи, додамо серверну частину окремим етапом (див. `TASKS.md`).

## Що є на сайті
11 модулів (урок + тест), тренажер «Шахрай чи ні», підсумковий іспит (15 випадкових питань) із друкованим сертифікатом, пам'ятка «10 правил» (`site/cheatsheet.html`), профілі учасників, світла й темна теми, адаптивна верстка.

## Публікація
