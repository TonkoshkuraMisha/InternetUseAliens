# Гайд для авторів

## Новий модуль
1. Створіть `content/modules/NN-назва/` з `lesson.md` і `quiz.json`.
2. Додайте `"NN-назва"` у `content/course.json` у потрібному місці.
3. `uv run internetusealiens validate`, потім `serve`.

## Шаблон уроку
```
# Назва
## Мета уроку
## Головне
## ... (приклади, правила, чек-лист)
## Практика      <- обов'язково
```
Підтримується: `#`–`###`, списки `- ` і `1. `, **жирний**, `код`.

## Правила для тестів
- Не менше 5 питань на модуль, id у форматі `mNN-qK` (перевіряється тестами).
- Типи: `single` (рівно одна відповідь), `multi`, `truefalse`.
- Пояснення обов'язкове й непорожнє: воно вчить.
- Хибні варіанти мають бути правдоподібними. Уникайте «жартівливих» відповідей.
- Підсумковий іспит і тренажер беруть матеріал із банку питань та `content/trainer.json`.

## Тренажер «Шахрай чи ні»
Елементи `content/trainer.json`: `kind`, `from`, `text`, `scam` (true/false), `explanation`. Має бути і шахрайство, і безпечні приклади.

## Оновлення
Раз на квартал перевіряйте актуальність схем шахрайства, назв налаштувань і контактів служб.
